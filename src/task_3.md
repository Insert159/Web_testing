# Рекомендации по обеспечению кроссбраузерной совместимости

## 1. Использовать CSS-нормализатор или сброс стилей

Чтобы избежать различий в отступах (как в примере с карточкой), всем проектам необходимо подключать CSS-Reset (например, `normalize.css` или `ress.css`). Это выровняет базовые стили браузеров.

## 2. Проверять адаптив в нескольких браузерных движках

Вместо эмуляции мобильных устройств только в Chrome DevTools, следует вручную тестировать контрольные точки (breakpoints) в Firefox (`Shift + Ctrl + M`) и родных инструментах Edge. Это помогает выявить проблемы с флексбоксами на разных движках, как в блоке с кружками.

## 3. Кастомизировать все элементы форм

Если требуется точный дизайн для `<select>`, удалите нативный стиль и стилизуйте элемент с нуля. Это единственный способ избежать различий во внешнем виде стрелки или скролла.
