# Задание 6. Тестирование UI веб-сайта


## Найденные отличия (Баг-репорты)

### Баг №1

| Поле | Значение |
|------|----------|
| Заголовок | На главной странице в блоке «Программа обучения» отсутствуют декоративные иконки в карточках слайдера и в блоках «Карьерный трек» / «Стажировка». |
| Серьёзность (Severity) | Major — критическая проблема с отображением контента. Основные визуальные элементы, идентифицирующие направления обучения (иконки), не отображаются, что ухудшает восприятие информации и нарушает целостность дизайна. |
| Приоритет (Priority) | High — дефект сильно влияет на визуальное качество продукта и доверие к бренду, так как пользователь не получает ожидаемый графический интерфейс, соответствующий эталонному макету. Требует исправления в первую очередь. |
| Шаги воспроизведения | 1. Открыть файл `21school.html` в любом современном браузере.<br>2. Прокрутить страницу до блока «Программа обучения» (секция с тёмным фоном, заголовок «Все участники обязательно изучают базовую программу...»).<br>3. Обратить внимание на слайдер с карточками (C/C++, Алгоритмы, Языки программирования).<br>4. Обратить внимание на карточки «Карьерный трек» и «Стажировка» ниже слайдера. |
| Ожидаемый результат | Каждая карточка слайдера и каждая карточка («Карьерный трек», «Стажировка») содержат уникальную декоративную иконку, соответствующую тематике карточки, как показано в макете Figma. |
| Фактический результат | В карточках слайдера и в карточках «Карьерный трек» / «Стажировка» отсутствуют иконки. Отображается только текст и фоновая заливка. |

### Баг №2

| Поле | Значение |
|------|----------|
| Заголовок | В навигационном меню (хедер) пункт «Корпоративное обучение» не содержит выпадающего подменю, в отличие от других пунктов. |
| Серьёзность (Severity) | Minor — несоответствие поведения элемента навигации. Функциональность навигации частично нарушена (отсутствует ожидаемое подменю), но основной контент сайта доступен. |
| Приоритет (Priority) | Medium — дефект влияет на удобство навигации и единообразие интерфейса. Рекомендуется исправить в ближайшем обновлении. |
| Шаги воспроизведения | 1. Открыть файл `21school.html` в браузере с шириной экрана более 1024px (десктопная версия).<br>2. Навести курсор мыши на пункт меню «О школе».<br>3. Навести курсор мыши на пункт меню «Поступающим».<br>4. Навести курсор мыши на пункт меню «Партнерам».<br>5. Навести курсор мыши на пункт меню «Корпоративное обучение». |
| Ожидаемый результат | При наведении курсора на пункт «Корпоративное обучение» должно появляться выпадающее подменю, аналогичное другим пунктам («О школе», «Поступающим», «Партнерам»). |
| Фактический результат | При наведении курсора на пункт «Корпоративное обучение» выпадающее подменю не появляется. Пункт ведёт себя как обычная ссылка, в то время как другие пункты имеют стрелку и выпадающий список. |

### Баг №3

| Поле | Значение |
|------|----------|
| Заголовок | В блоке «Программа обучения» под слайдером содержится орфографическая ошибка в тексте: слово «следующие» написано как «слудующие». |
| Серьёзность (Severity) | Trivial — дефект не влияет на функциональность сайта, но портит впечатление о качестве контента и может снижать доверие пользователей. |
| Приоритет (Priority) | Low — ошибка носит косметический характер. Исправление не требует значительных ресурсов и может быть выполнено в плановом порядке. |
| Шаги воспроизведения | 1. Открыть файл `21school.html` в любом браузере.<br>2. Прокрутить страницу до блока «Программа обучения».<br>3. Пройти слайдер с вкладками (например, выбрать направление «Разработчик ПО»).<br>4. Найти текст под карточками «Карьерный трек» и «Стажировка»: «После стажировки каждый участник может изучить глубже слудующие направления». |
| Ожидаемый результат | Текст должен содержать корректное написание: «После стажировки каждый участник может изучить глубже следующие направления». |
| Фактический результат | В тексте допущена орфографическая ошибка: «слудующие» вместо «следующие». |
